# LoadEncryptedFile(filename: string)

Runs an encrypted file from the script folder. The partner of `EncryptFile`.

Parameters
- `filename: string`: name of the encrypted file.

Returns
- Nothing.

Example (Lua)
```lua
LoadEncryptedFile('script.lua')
```
